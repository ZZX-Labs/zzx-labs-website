CyberChefZZX build source

This repository directory contains the ZZX overlay source only. The CyberChef workflow replaces this file in the deployment artifact with the current official GCHQ CyberChef release.

Published routes: /cyberchef/ is the upstream CyberChef application with ZZX styling and controls layered on top; /cyberchef/app/ is the untouched native upstream application.
