ZZXCyberChef

A locally hosted GCHQ CyberChef workspace with a strict trust boundary: /cyberchef/app/ is the pristine upstream production application, while this page loads that exact local copy first and layers ZZX-Labs presentation, controls, themes, layouts, macro banks, recipes, and analyst ergonomics afterward.

No upstream CyberChef HTML, JavaScript, CSS, workers, or assets are rewritten by the ZZX layer. Modified mode is a same-origin wrapper. Native mode and direct navigation to /cyberchef/app/ remain the clean baseline for comparison.

Programmable Presets

Macro Editor

Each lower encoder owns a 16-slot bank. Every slot can be either an operation macro or a complete CyberChef recipe preset with operation arguments. Save user macros, capture the live recipe, and press the encoder to execute or restore it.

Upstream Provenance

GCHQ CyberChef: Project, History, and Trust

CyberChef describes itself as “The Cyber Swiss Army Knife”: a client-side web application for manipulating, decoding, encoding, encrypting, compressing, parsing, hashing, and inspecting digital data in the browser.

Origins

Analyst innovation time

The upstream README states that CyberChef was conceived, designed, built, and incrementally improved by an analyst during their 10% innovation time over several years.

Architecture

Browser-side processing

CyberChef is designed to process input and recipes locally in the browser. Its downloadable production build can be hosted on a web server or used in segregated environments.

Open Source

Public contribution model

The project is developed in public on GitHub. Contributors submit pull requests and, for first contributions, are prompted to sign the GCHQ Contributor Licence Agreement.

Security and trust

CyberChef’s own download/help text warns that unofficial builds could be modified to exfiltrate input or recipes and recommends the official open-source version when accessible. This page therefore exposes the exact native local baseline separately and links directly to GCHQ’s official source and releases.
