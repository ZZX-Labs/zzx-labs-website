Blog API

Browse the ZZX-Labs R&D article index and consume the same structured data used by the Journal, Archive and RSS pages. These public feeds work on a static website without a Python server.

Article listings may include historical or pending editorial records. An entry's presence in the catalog does not mean its content, original publication date or claims have been independently verified.

Integration and editorial access

Retrieve the public catalog from Python, Go, or a terminal:

curl -fsSL https://zzx-labs.io/blog/catalog.json

Records include title, url, date, description, category, tags, thumb, and editorial publication fields.

Creating, modifying and deleting articles

The public GitHub Pages directory is read-only. Authoring actions require the separate authenticated ZZX-BLOG publisher service. An HTML page cannot provide secure post submission or update repository contents by itself.

For contributor access, contact the ZZX-Labs editorial team. Browse the Blog, Archive or RSS directory.
