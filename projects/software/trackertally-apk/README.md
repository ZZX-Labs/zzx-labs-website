# TrackerTally (APK)

`/projects/software/trackertally-apk/`

Native Android APK version of TrackerTally for mobile habit tracking with offline-first storage and controlled export.

This package is the browser/mobile companion, not a fabricated APK. It provides quick session logging, local history, plain JSON export, and optional PBKDF2/AES-GCM encrypted export.

The native Kotlin/Android implementation should use Android platform storage and keystore facilities.
