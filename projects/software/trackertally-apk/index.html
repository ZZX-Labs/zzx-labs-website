TrackerTally (APK)

Native Android APK version of TrackerTally for mobile habit tracking with offline-first storage and controlled export.

The catalog points to /projects/software/trackertally-apk/trackertally-apk.apk, but this deploy does not fabricate an APK binary. The page is the browser/mobile companion and reference interface for the Kotlin/Android build.
