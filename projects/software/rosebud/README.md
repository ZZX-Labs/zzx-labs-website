# RoseBud

`/projects/software/rosebud/`

RoseBud is a relentless, hilarious, drill-sergeant-style personal fitness coach that compresses daily conditioning, core durability, and strength maintenance into 30–120 minute sessions with mandatory breathwork + stretching rails and adaptive difficulty based on performance and recovery.

Browser companion: 30–120 minute adaptive session builder, breath/warm-up, conditioning, core, strength, stretching, timer, effort/recovery logs, JSON export. General fitness guidance only.
