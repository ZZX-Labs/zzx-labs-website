LOCAL-FIRST

      
Archive Safety Boundary

      

        Raw imported files are never uploaded by the supplied page. Archive inventory code
        reads ZIP/TAR structures without extracting them onto the host filesystem. Persisted
        catalog records store derived metadata, tags, fingerprints, archive entry names, and
        extracted text; raw source files remain under user control.
