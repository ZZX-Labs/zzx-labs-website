# BlinkeeQR Encoding Standard (BQRES)

Animated optical data-encoding protocol reference implementation.

**Version:** 0.1.0-alpha  
**License:** MIT  
**Category:** protocol

The browser edition converts text or binary files into deterministic data frames, adds CRC-32 integrity fields and one XOR parity frame per group, renders binary optical frames with finder markers, animates them at selectable frame rates, exports sequence JSON, and reconstructs one missing data frame per parity group.

BQRES is QR-like but is not ISO/IEC QR Code.

Deploy directly into `/projects/software/blinkeeqr/`.

`logo.png` is intentionally omitted until final artwork is supplied.
