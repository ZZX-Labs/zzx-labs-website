ALPHA PACKET MODEL
Protocol
BQRES alpha sequence
- source: arbitrary byte stream
- data frame: sequence index, group, slot, original length, CRC-32, base64 payload
- parity frame: XOR of fixed-size group payload buffers
- recovery: one missing data frame per parity group
- temporal order: monotonically increasing frame index
- optical symbol plane: binary cells + 3 finder markers
- sequence digest: SHA-256 of original source bytes

This reference format is intentionally versioned and self-describing.
