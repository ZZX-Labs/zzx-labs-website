# HashPig

Browser research companion for statistical geographic attribution experiments.

Imports aggregate public-node/pool signals, combines them with explicit weights, reports uncertainty bands, visualizes proxy shares, and exports the full research model.

The page performs no network scanning. Bitcoin node geography is **not** equivalent to mining-hashrate geography; outputs are explicitly treated as noisy statistical proxy estimates rather than direct national attribution.

Deploy directly into `/projects/software/hashpig/`.

`logo.png` is intentionally omitted.
