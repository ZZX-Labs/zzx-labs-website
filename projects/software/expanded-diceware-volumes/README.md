# Expanded Diceware Volumes

Browser workbench for validating and using themed or locale-aware Diceware wordlists.

Features local wordlist import, standard 5d6 code parsing, duplicate detection, SHA-256 metadata, Web Crypto rejection-sampled word selection, manual dice-code decoding, and entropy estimates.

No fabricated official wordlist is bundled. Import the actual volume you intend to use. Real passphrases should remain private and should not be pasted into chats or third-party sites.

Deploy directly into `/projects/software/expanded-diceware-volumes/`.

`logo.png` is intentionally omitted.
