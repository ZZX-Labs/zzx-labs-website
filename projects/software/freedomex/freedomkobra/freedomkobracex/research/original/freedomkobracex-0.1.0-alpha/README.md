# FreedomKobraCEX

Functional browser research companion for the manifest-defined United States centralized exchange clone environment.

The web build is simulation-only. It does not connect to exchanges or wallets, accept API credentials, submit live orders, custody Bitcoin, or perform settlement.

Deploy directly into `/projects/software/freedomkobracex/`.

`logo.png` is intentionally omitted so existing artwork is not overwritten.
