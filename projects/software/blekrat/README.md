# BlekRAT

**INTERNAL – Not for public distribution.**  
**License:** Proprietary / Internal  
**Version:** 0.1.0-alpha

Private administrator orchestration project for authorized lab/testbed environments.

The browser subpage is deliberately limited to host inventory, allowlisted maintenance-task planning, sanitized telemetry import, SHA-256 hash-chained audit records, and internal-plan export. It does not open SSH/control channels, accept credentials, run arbitrary commands, deploy agents, or execute tasks remotely.

Deploy directly into `/projects/software/blekrat/`.

`logo.png` is intentionally omitted so existing project artwork is not overwritten.
