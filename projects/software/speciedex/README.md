# Speciedex

`/projects/software/speciedex/`

Speciedex is a global species taxonomy engine using AI-augmented classification, peer-verified data, and Bitcoin/Lightning Network incentives to maintain decentralized biodiversity records—explicitly excluding Homo sapiens.

The browser companion provides a local species catalog, search, interoperable Speciedex JSON import/export, deterministic local observation-to-candidate ranking, peer-verification events, provenance hashes, and explicit exclusion of `Homo sapiens`.

The browser does not pretend to run the native TensorFlow classifier or execute live Bitcoin/Lightning incentive payments.
