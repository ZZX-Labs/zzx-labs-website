# CyberChefLua

Lua CyberChefKit implementation for embedded scripting and OpenResty/Nginx integration.

Deploy directly into `/projects/software/cyberchefkit/cybercheflua/`.

Version `0.1.0-alpha`, CLA Apache. The web companion generates Lua modules, CLI scripts, LuaRocks metadata, OpenResty handler scaffolds, and reference vectors. `logo.png` is intentionally omitted.
