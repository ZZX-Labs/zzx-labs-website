# CyberChefGo

Go CyberChefKit implementation companion.

**Version:** 0.1.0-alpha  
**License:** CLA Apache

The browser subpage executes reference transforms, generates a Go package, CLI, `go.mod`, optional local HTTP service scaffold, cross-build command matrix, and deterministic vectors. Native compilation remains the Go toolchain's job.

Deploy directly into `/projects/software/cyberchefkit/cyberchefgo/`.

`logo.png` is intentionally omitted so existing artwork is not overwritten.

Parent project: `/projects/software/cyberchefkit/`.
