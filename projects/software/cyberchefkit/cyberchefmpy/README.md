# CyberChefMicroPython

MicroPython CyberChefKit implementation for ESP32 and embedded targets.

Deploy directly into `/projects/software/cyberchefkit/cyberchefmpy/`.

Version `0.1.0-alpha`, CLA Apache. The web companion generates memory-conscious modules, board profiles, serial-shell tooling, and portable deployment bundles. `logo.png` is intentionally omitted.
