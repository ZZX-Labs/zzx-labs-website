# CyberChefRust

Rust / WebAssembly CyberChefKit implementation companion.

**Version:** 0.1.0-alpha  
**License:** CLA Apache

The browser subpage executes reference transforms, generates Rust library/CLI code, `Cargo.toml`, a wasm-bindgen interface scaffold, build commands, deterministic vectors, and a portable bundle. It does not fabricate a compiled native or `.wasm` binary.

Deploy directly into `/projects/software/cyberchefkit/cyberchefrs/`.

The canonical manifest slug is `cyberchefrust`; the deployment route is `cyberchefrs`.

`logo.png` is intentionally omitted so existing artwork is not overwritten.

Parent project: `/projects/software/cyberchefkit/`.
