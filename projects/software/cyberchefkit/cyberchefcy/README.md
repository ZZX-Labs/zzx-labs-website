# CyberChefCython

Cython-accelerated CyberChefKit backend companion.

**Version:** 0.1.0-alpha  
**License:** CLA Apache

The browser subpage provides reference transform execution, Cython `.pyx` API generation, `pyproject.toml` / `setup.py` generation, deterministic test vectors, and portable bundle export. Native performance requires compiling the generated Cython extension.

Deploy directly into `/projects/software/cyberchefkit/cyberchefcy/`.

`logo.png` is intentionally omitted so existing artwork is not overwritten.

Parent project: `/projects/software/cyberchefkit/`.
