# CyberChefPerl

Perl CyberChefKit implementation companion for legacy systems and Unix text-processing workflows.

**Version:** 0.1.0-alpha  
**License:** CLA Apache

The browser subpage executes reference transforms, generates a Perl module, CLI/STDIN filter, Unix examples, `Makefile.PL`, Test::More vectors, and a portable bundle.

Deploy directly into `/projects/software/cyberchefkit/cyberchefperl/`.

`logo.png` is intentionally omitted so existing artwork is not overwritten.

Parent project: `/projects/software/cyberchefkit/`.
