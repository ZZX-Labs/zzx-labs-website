# CyberChefPHP

PHP CyberChefKit implementation for web and LAMP stack environments.

**Version:** 0.1.0-alpha  
**License:** CLA Apache

The browser subpage executes reference transforms and generates a PHP library, Composer package, CLI, bounded allowlist-based HTTP endpoint, PHPUnit vectors, and a portable integration bundle.

Deploy directly into `/projects/software/cyberchefkit/cyberchefphp/`.

Parent project: `/projects/software/cyberchefkit/`.

`logo.png` is intentionally omitted so existing artwork is not overwritten.
