# CyberChefKit

Unified multi-language, offline-first transformation and analysis suite browser companion.

**Version:** 0.2.0-alpha  
**License:** CLA Apache

Includes local recipe execution, file analysis, implementation matrix, code/CLI generation, local-server policy configuration, and JSON exports. Native backends remain language-specific repositories/tools.

Deploy directly into `/projects/software/cyberchefkit/`.

`logo.png` is intentionally omitted so existing artwork is not overwritten.

## Canonical website tree

`/projects/software/cyberchefkit/` is the parent directory.

Runtime/language implementations are nested children, including `cyberchefc/`, `cyberchefcpp/`, `cyberchefpy/`, `cyberchefcy/`, `cyberchefcsharp/`, `cyberchefgo/`, `cyberchefrs/`, `cyberchefjava/`, `cyberchefkt/`, `cyberchefr/`, and `cyberchefperl/`.

Individual child deployment ZIPs are flat and are intended to be extracted directly into their corresponding nested directory.
