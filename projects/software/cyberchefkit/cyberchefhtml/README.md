# CyberChefHTML

Static HTML offline CyberChef interface requiring no runtime dependencies.

**Version:** 0.1.0-alpha  
**License:** CLA Apache

The browser edition runs reference transforms and generates a self-contained HTML utility with embedded CSS/JavaScript, CSP controls, no-CDN deployment, offline-policy verification, and SHA-256 integrity fingerprinting.

Deploy directly into `/projects/software/cyberchefkit/cyberchefhtml/`.

Parent project: `/projects/software/cyberchefkit/`.

`logo.png` is intentionally omitted so existing artwork is not overwritten.
