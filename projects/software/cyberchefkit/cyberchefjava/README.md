# CyberChefJava

Java/JVM CyberChefKit implementation companion.

**Version:** 0.1.0-alpha  
**License:** CLA Apache

The browser subpage executes reference transforms, generates Java library and CLI code, a Maven `pom.xml`, Android integration snippets, JUnit vectors, and a portable bundle.

Deploy directly into `/projects/software/cyberchefkit/cyberchefjava/`.

`logo.png` is intentionally omitted so existing artwork is not overwritten.

Parent project: `/projects/software/cyberchefkit/`.
