# CyberChefJS

JavaScript/Node CyberChefKit implementation for browser and backend transform pipelines.

**Version:** 0.1.0-alpha  
**License:** CLA Apache

The browser subpage runs real JavaScript reference transforms and generates ES module/CommonJS libraries, a Node CLI, `package.json`, webpack UMD configuration, a browser demo, Node test vectors, and portable bundles.

Deploy directly into `/projects/software/cyberchefkit/cyberchefjs/`.

Parent project: `/projects/software/cyberchefkit/`.

`logo.png` is intentionally omitted so existing artwork is not overwritten.
