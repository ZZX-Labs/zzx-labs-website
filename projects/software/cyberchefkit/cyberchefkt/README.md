# CyberChefKotlin

Kotlin CyberChefKit implementation companion for JVM and Android workflows.

**Version:** 0.1.0-alpha  
**License:** CLA Apache

The browser subpage executes reference transforms, generates Kotlin APIs, Gradle Kotlin DSL files, a CLI, Android integration snippets, deterministic tests, and a portable bundle.

Deploy directly into `/projects/software/cyberchefkit/cyberchefkt/`.

`logo.png` is intentionally omitted so existing artwork is not overwritten.

Parent project: `/projects/software/cyberchefkit/`.
