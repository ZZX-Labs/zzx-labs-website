# SpeciedexGeneticBank

`/projects/software/speciedexgeneticbank/`

SpeciedexGeneticBank links non-human species records with genomes, genes, sequences, markers, specimens, accession identifiers, repositories, and genetic research through interoperable provenance-aware records.

The browser companion links non-human species records to repository/accession/gene/marker/specimen metadata, computes optional local DNA length/GC statistics, hashes record metadata, and exports interoperable link records.

`Homo sapiens` is excluded from this product's scope. Raw sequence text is not stored in exported records.
