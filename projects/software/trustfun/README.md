# TrustFun

`/projects/software/trustfun/`

TrustFun is a financial planning and savings system designed for long-term goal tracking, budgeting, and structured capital allocation with optional Bitcoin integration.

The browser workbench provides local savings goals, contribution history, allocation metadata, progress visualization, manually entered Bitcoin reference pricing, arithmetic savings scenarios, and JSON/CSV export.

It performs no custody, trading, live-price lookup, or personalized investment recommendations.
