# Stephenizer

`/projects/software/stephenizer/`

Stephenizer is a voice FX transformer using text-to-speech prosody shaping and formant filters to produce electrolarynx-style synthetic voices with adjustable tone and timbre parameters.

The browser companion provides generic browser TTS, rate/pitch/volume preview controls, synthetic electrolarynx-style DSP parameters, and native effect-job export.

It does not clone or imitate a specific person's voice.
