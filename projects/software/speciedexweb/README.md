# SpeciedexWeb

`/projects/software/speciedexweb/`

SpeciedexWeb is the browser-based public interface for searching, reading, comparing, learning from, and downloading Speciedex records, with species pages, taxonomic navigation, maps, media, and open-data access.

Functional browser companion:
- interoperable Speciedex JSON import;
- search and taxonomic filtering;
- two-record comparison;
- public/open-data JSON export;
- explicit local/offline operation when no API is configured.

Version: `0.1.0-alpha`
