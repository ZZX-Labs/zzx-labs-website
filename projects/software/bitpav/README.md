# BitPav (Bitcoin Proof-of-Worth Tracker)

Bitcoin purchase/sale tracker and proof-of-worth analytics dashboard.

**Version:** 0.1.0-alpha  
**License:** MIT

The browser edition tracks buys, sells, fees, average cost basis, realized/unrealized P/L, market value, and lifetime performance. It supports manual pricing or public spot-price polling, plus JSON/CSV portability and local charts.

The accounting model is transparent but not jurisdiction-specific tax advice.

Deploy directly into `/projects/software/bitpav/`.

`logo.png` is intentionally omitted so existing site artwork is not overwritten.
