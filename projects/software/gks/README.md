# GKSs (Glyph Key Sprites)

Procedural sprite forge using a public/non-secret identifier and optional d6 rolls. It deterministically derives a SHA-256 seed, sprite, palette, rarity, and traits, with PNG and metadata export.

Never paste wallet private keys, seed phrases, xprvs, passwords, or recovery material.

Deploy directly into `/projects/software/gks/`.

`logo.png` is intentionally omitted.
