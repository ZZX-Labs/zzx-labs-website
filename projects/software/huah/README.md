# Huah

Internal browser workbench for lawful aggregation and analysis of publicly available wanted notices and bulletins.

Supports JSON/CSV import, field normalization, search/filtering, per-record printable views, source tracking, and normalized exports.

The page uses public or authorized data only. It does not implement facial recognition, private-database access, credential collection, or hidden-location inference.

Deploy directly into `/projects/software/huah/`.

`logo.png` is intentionally omitted.
