# SOIVA

`/projects/software/soiva/`

SOIVA (Schmidt Ocean Institute Video Archiver) performs bulk ingestion, cut-point detection, and tagging of marine expedition footage using computer vision and metadata extraction pipelines.

The browser companion supports local marine video ingestion, SHA-256 fingerprints, media metadata, local tagging/notes, coarse sampled luminance cut-point detection, and archive export.

The native project uses TensorFlow, OpenCV, SQLAlchemy, and FFmpeg for the full computer-vision and archival pipeline.
