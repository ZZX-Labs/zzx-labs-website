# ZZX-VCS

`/projects/software/zzxvcs/`

Voice Changer System — advanced real-time voice modulation suite integrating pitch, formant, reverb, delay, chorus, distortion, and bit-crush effects. Supports live microphone input and routed outputs via Virtual Audio Cable, OBS, or Discord. Features PyQt5 GUI and CLI modes for performance tuning, voice profile saving, and dynamic FX chains with MIDI/LFO automation.

The browser workbench provides a real Web Audio microphone effects chain with band-pass/formant-like filtering, distortion, delay, gain, metering, generic profile export, and MIDI-map planning. Native Python source implements a generic real-time band-pass/gain audio filter with `sounddevice` and SciPy.

The project intentionally does not clone or impersonate a specific person's voice.
