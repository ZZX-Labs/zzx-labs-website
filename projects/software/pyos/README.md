# PyOS

`/projects/software/pyos/`

PyOS is an open-source operating system written in Python targeting x86/x64 environments and cross-platform app-layer compatibility for Linux, Windows, macOS, Android, and iOS.

The browser page is a functional architecture simulator for boot state, process records, virtual mounts, app-layer package records, target-platform profiles, and JSON export.

It does not pretend to provide a real kernel, driver stack, or bootable operating-system image inside the browser.

Native dependencies: `python3, ctypes, flask, sqlalchemy, requests`.

Version: `0.2.0-alpha`
