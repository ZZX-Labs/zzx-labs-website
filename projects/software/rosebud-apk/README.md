# RoseBud (APK)

`/projects/software/rosebud-apk/`

RoseBudAPK is the mobile field-device companion to RoseBud, using phone sensors (GPS, accelerometer/gyro, mic, camera) to verify cadence, distance/steps, form confidence, and session timing, then syncing locally and securely with the desktop basestation.

The browser/reference companion provides opt-in GPS tracking, distance calculation, DeviceMotion sampling, rough acceleration-threshold cadence/step-like events, session timing, local media capture/selection, SHA-256 media fingerprints, and session export.

It does not fabricate an APK binary and does not claim certified pedometer or automatic form-verification accuracy.
