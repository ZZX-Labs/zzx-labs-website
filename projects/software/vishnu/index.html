Vishnu

Vishnu is a Python GUI ecosystem for synchronized audio visualizations designed to complement VLC visualizers and other media players.

The browser build performs real local Web Audio analysis. Direct VLC control/status polling belongs to the native bridge; the web page can import a VLC status JSON snapshot without pretending it has live VLC access.
