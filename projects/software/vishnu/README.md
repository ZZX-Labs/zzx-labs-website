# Vishnu

`/projects/software/vishnu/`

Vishnu is a Python GUI ecosystem for synchronized audio visualizations designed to complement VLC visualizers and other media players.

The browser workbench performs actual local Web Audio analysis and supplies spectrum bars, waveform, radial, and Lissajous-like visual modes, plus RMS/peak/spectral-centroid metrics and PNG snapshots. It can import a local VLC `status.json` snapshot and export a native VLC bridge configuration.

Direct VLC polling and media-player integration remain native/local bridge capabilities.
