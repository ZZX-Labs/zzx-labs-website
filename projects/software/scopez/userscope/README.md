# UserScope

Functional browser companion for the manifest-defined UserScope analysis project.

The web build operates on user-supplied public, authorized, self-owned, or lab data and performs no live private-data lookup. Its analysis output is descriptive/probabilistic and should not be treated as proof of real-world identity or ownership unless independently established.

Deploy directly into `/projects/software/userscope/`.

`logo.png` is intentionally omitted.
