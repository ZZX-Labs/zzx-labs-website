# BitPet

Bitcoin-linked virtual pet ecosystem.

**Version:** 0.1.0-alpha  
**License:** MIT

The browser edition provides local pet progression, training/play/rest actions, deterministic collectible traits, optional blockchain-reference metadata, sanitized Lightning event hooks, history, and JSON import/export.

It is non-custodial. No wallet seed, private key, macaroon, or wallet password is stored in the page.

Deploy directly into:

```text
/projects/software/bitpet/
```

`logo.png` is intentionally not included. The page hides the missing logo until final artwork is added.
