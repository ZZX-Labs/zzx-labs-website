ZZX-Core

ZZX-Core is the unified backend controller and orchestration system for all ZZX services—providing a GUI host for modular APIs, stack control, and mirrored backend operations.

Container-free implementation: no Docker. ZZX-Core models direct local Python/Flask/PyQt services and emits inspectable stack/NGINX configuration rather than hiding services behind containers.
