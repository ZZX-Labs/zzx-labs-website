# VLC Ticker

`/projects/software/vlc-ticker/`

VLC Ticker is a PyQt5 GUI overlay that displays the currently playing VLC media’s title and tag metadata (ID3-like) as a live, customizable ticker.

The browser workbench includes a real scrolling overlay designer, metadata field selection, colors/font/speed/opacity controls, VLC status JSON import, and configuration export.

The package also includes `native/vlc_ticker.py`, an always-on-top PyQt5 overlay that polls VLC locally.
