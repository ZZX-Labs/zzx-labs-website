PROJECT

        
Overview

        

          TerVIS identifies and analyzes terrestrial biodiversity media using image inference,
          temporal video analysis, camera frames, motion-pattern detection, and audio features.
          The web edition ports the native TensorFlow/OpenCV/FFmpeg workflow into browser APIs.

LOCAL-FIRST

      
Browser Security Boundary

      

        Local images, videos, audio files, and webcam frames remain inside the browser.
        Network access is used only when the user invokes model functionality requiring
        TensorFlow.js, MobileNet, or a custom model URL.
