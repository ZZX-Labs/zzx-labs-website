PROJECT

        
Overview

        

          TerVIS is designed around TensorFlow-based terrestrial species recognition with OpenCV/FFmpeg
          media processing. The web port replaces native media decoding with browser media APIs and Canvas,
          while TensorFlow.js provides an inference path for compatible models.
