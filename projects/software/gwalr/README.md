# GWALR (Global War Art Loss Registry)

Browser registry workbench for documenting cultural-heritage loss, theft, damage, destruction, recovery, and risk during armed conflicts.

Supports public-source citations, optional evidence-file SHA-256 fingerprints, verification states/history, local search, and JSON/CSV export.

Deploy directly into `/projects/software/gwalr/`.

`logo.png` is intentionally omitted.
