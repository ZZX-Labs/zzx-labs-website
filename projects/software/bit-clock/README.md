# Bit-Clock

Bitcoin block-height clock, halving countdown, epoch statistics, subsidy schedule, and emission visualizer.

**Version:** 0.1.0-alpha  
**License:** MIT

The browser computes consensus subsidy math locally and can fetch live height from an Esplora/mempool API. Halving ETA uses the conventional 600-second average block interval and is therefore an estimate.

Deploy directly into:

```text
/projects/software/bit-clock/
```

`logo.png` is intentionally omitted until final artwork is supplied.
