VLC AlarmClock

VLC AlarmClock schedules VLC to open specific media or playlists at defined times with optional fade-in, repeat, and profile-based alarm presets.

The deploy includes a real native scheduler helper in native/. Browser scheduling is a local planning/test interface; actual VLC launch occurs only through the native helper you run yourself.
