# BlockClock

Bitcoin network monitor for block height, mempool activity, fee rates and hardware-display integration.

**Version:** 0.1.0-alpha  
**License:** MIT

The browser edition supports live mempool.space-compatible public endpoints or manual data, epoch/halving context, subsidy display, mempool/fee history charts, threshold alerts, browser notifications, and a hardware-adapter API for trusted local integrations.

Deploy directly into `/projects/software/blockclock/`.

`logo.png` is intentionally omitted until final artwork is supplied.
