# Safai Karta

`/projects/software/safai_karta/`

Safai Karta is a Python video filename filtering, normalization, and sanitization utility that detects series patterns, cleans filenames, and organizes directories for metadata preparation.

The browser companion previews filename cleanup, strips common release/noise tokens, detects `SxxEyy`/`NxM` series patterns, standardizes names, and exports JSON or a reviewable Bash rename plan.

It does not rename selected local files directly.
