# Vikram

`/projects/software/vikram/`

Vikram is a Python GUI explorer for local files that adds schema-aware search, inline viewers, and optional VR-oriented navigation controls and interfaces.

The browser implementation provides explicit local file/directory selection, metadata indexing, text/JSON/image/audio/video previews, JSON top-level-key extraction, multi-field search, optional SHA-256 hashing, a spatial file map, and metadata index export.

Browser sandboxing is respected: Vikram does not crawl arbitrary filesystem paths without user selection.

Version: `0.2.0-alpha`
