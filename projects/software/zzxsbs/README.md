# ZZX-SBS

`/projects/software/zzxsbs/`

Site Builder System — unified page generator for projects, portfolios, and docs from a single manifest. Includes CLI and GUI modes with live preview and publication automation.

The browser builder imports or edits project manifests, generates page/manifest/README/project-control files, previews the resulting page content, exports individual files or a complete bundle JSON, and keeps publication review-controlled rather than silently deploying.

A native Jinja2 builder is included.
