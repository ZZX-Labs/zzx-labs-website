# Cryptainer

Bitcoin-oriented encrypted cold-storage/container workbench.

**Version:** 0.1.0-alpha  
**License:** MIT

The browser edition provides PBKDF2-HMAC-SHA256 + AES-256-GCM encrypted containers, encrypted local file payloads, public GPG fingerprint references, M-of-N policy manifests, CLTV/CSV timelock planning metadata, hash-chained audit records, and encrypted import/export.

It does not generate Bitcoin private keys, sign transactions, custody GPG private keys, or broadcast transactions. The browser build is not a hardware wallet.

Deploy directly into `/projects/software/cryptainer/`.

`logo.png` is intentionally omitted so existing artwork is not overwritten.
