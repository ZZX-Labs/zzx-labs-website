# SD-GUI

`/projects/software/sd-gui/`

SD-GUI is a Stable Diffusion graphical interface featuring model management, parameter presets, queueing, prompt history, and gallery exports for AI-generated art workflows.

The browser companion provides Stable Diffusion job construction, model/scheduler parameters, seeds, queueing, prompt history, local gallery import, image SHA-256 provenance, queue export, and gallery-manifest export.

Actual generation belongs in the native Torch/Diffusers/Transformers stack and is not faked in the static browser page.
