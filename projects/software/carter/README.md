# Carter (CCTV Streaming System)

Local-first CCTV streaming and video-management workbench.

**Version:** 0.1.0-alpha  
**License:** MIT

The browser edition supports permission-based local camera capture, local video playback, MediaRecorder recording, snapshots, source inventory, frame-difference motion detection, event logging, and AI/relay adapter hooks. RTSP, FFmpeg/OpenCV pipelines, and authenticated remote relay remain native/server-side integrations.

Use only with cameras and locations you are authorized to monitor.

Deploy directly into `/projects/software/carter/`.

`logo.png` is intentionally omitted until final artwork is supplied.
