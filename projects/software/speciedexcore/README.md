# SpeciedexCore

`/projects/software/speciedexcore/`

SpeciedexCore provides the full-node and light-node backends for the Speciedex protocol, hosting inference kernels, taxonomy services, and archival nodes that process high-volume global biodiversity data.

The browser companion builds full/light/archive/inference node profiles, service/port plans, imports interoperable Speciedex datasets, performs local record queries, generates health snapshots, and exports node profiles.

It does not open network listeners, store credentials, or execute remote inference in-browser.
