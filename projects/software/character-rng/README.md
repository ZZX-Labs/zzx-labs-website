# Character RNG

Seed-locked structured character + portrait pipeline planner.

**Version:** 0.1.0-alpha  
**License:** MIT

The browser edition creates deterministic character records, style locks, SHA-256 fingerprints, Stable-Diffusion-compatible prompt jobs, and repeatable variation seeds. Actual image generation is delegated to an explicitly registered provider rather than being fabricated in-browser.

Deploy directly into `/projects/software/character-rng/`.

`logo.png` is intentionally omitted until final artwork is supplied.
