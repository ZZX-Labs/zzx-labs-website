# RGBRNG

`/projects/software/rgbrng/`

RGBRNG is a color-based random number generator and palette explorer deriving entropy from live pixel differentials or static gradient values for cryptographic art, design, and randomness visualization.

Browser companion: local-image/gradient pixel differentials, palette generation, and an explicit Web Crypto CSPRNG + SHA-256 mixing path. Raw pixels are not claimed as cryptographically secure by themselves.
