# SpeciedexArchives

`/projects/software/speciedexarchives/`

SpeciedexArchives is the long-term preservation layer for provider snapshots, historical classifications, releases, documents, media, schemas, licenses, manifests, reports, checksums, and reproducible recovery packages.

The browser companion hashes local artifacts, records licenses/providers/schema versions, builds append-only snapshot metadata, chains snapshots by SHA-256, verifies the local chain, and exports recovery/preservation manifests.

The static page stores metadata only, not archive payloads.
