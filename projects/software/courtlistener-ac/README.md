# CourtListener-AC

CourtListener oral-argument audio collector companion and local transcript corpus workbench.

**Version:** 0.1.0-alpha  
**License:** MIT

The browser edition catalogs local audio, fingerprints it with SHA-256, parses timestamped speaker transcripts, aligns transcript segments to playback, searches the local corpus, and exports acquisition queues/corpus JSON. Native Python handles CourtListener fetching, BeautifulSoup parsing, FFmpeg/Pydub processing, and SQL persistence.

Deploy directly into `/projects/software/courtlistener-ac/`.

`logo.png` is intentionally omitted so existing artwork is not overwritten.
