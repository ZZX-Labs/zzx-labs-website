ZZX-BBC

ZZX-BBC is a LoRA mesh communicator designed in a BlackBerry-style form factor—offering encrypted text, email, audio/video, and file transfers over Wi-Fi, GSM, 5G, and LoRA mesh networks.

INTERNAL – Not for public distribution. This static build models authorized mesh nodes, transport plans, routes, and encrypted local message envelopes. It does not claim to transmit over a live LoRA/GSM/5G radio.
