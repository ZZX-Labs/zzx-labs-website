# ZZX-BBC

`/projects/software/zzxbbc/`

ZZX-BBC is a LoRA mesh communicator designed in a BlackBerry-style form factor—offering encrypted text, email, audio/video, and file transfers over Wi-Fi, GSM, 5G, and LoRA mesh networks.

The browser workbench provides authorized-node inventory, LoRA/Wi-Fi/GSM/5G transport profiles, deterministic route planning, store-and-forward metadata, PBKDF2/AES-GCM encrypted local message envelopes, decryption, and mesh/envelope export.

It does not claim live radio transmission or collect carrier/Wi-Fi credentials.
