AlexBerossusGPT

        

          AlexBerossusGPT is a general learning and review environment inspired by the
          quizmaster tradition of Alex Trebek and the scholarly tradition of Berossus:
          structured questioning, broad knowledge, source study, teaching, and recall.

LOCAL-FIRST

      
Learning Data Boundary

      

        Imported source documents, flashcards, quiz results, and review state remain in
        the browser unless the user explicitly chooses an external model provider. The
        page does not embed cloud API keys; compatible hosted models should be reached
        through a trusted server-side proxy.
