# Shairi Badalna

`/projects/software/shairi_badalna/`

Shairi Badalna is a rules-based video renamer and sorter for large media libraries, preparing cleaned filenames and directories for MetaTagDB ingestion and tagging automation.

The browser companion implements configurable cleanup rules, release-token removal, season/episode detection, destination-folder planning, before/after previews, and JSON/CSV export for MetaTagDB preparation.

It does not directly rename or move local files.
