# VideoSort

`/projects/software/videosort/`

VideoSort is a modular Python toolkit for sanitizing, organizing, and formatting video filenames across large archives using rules, patterns, and exportable manifests.

The browser implementation accepts selected files or pasted filenames, applies configurable normalization rules, detects `SxxEyy`/`NxM` episode patterns and years, builds destination folders, previews all changes, and exports JSON, CSV, Bash, and PowerShell plans.

No direct file rename/move occurs in-browser.
