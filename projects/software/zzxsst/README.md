# ZZX-SST

`/projects/software/zzxsst/`

Site Scaffolding Tool — modular generator for uniform project pages, docs, and portfolios. CLI and PyQt5 GUI modes with automatic README/LICENSE imports and per-project hooks.

The browser scaffolder generates uniform project roots from slug/title/blurb/version/license inputs, imports README/LICENSE text, includes optional per-project hooks, previews the scaffold, and exports a complete scaffold JSON. A native Jinja2 scaffolder is included.
