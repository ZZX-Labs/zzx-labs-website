WireFeed

RSS news and update feed GUI built in Python, offering keyword filtering, deduplication, overlay modes, and exportable lists for research dashboards.

The page contains a real RSS/Atom parser for local/pasted feeds, and the package includes a native feedparser CLI. Direct website fetching is attempted only when the target feed allows CORS.
