# BitGaming

Bitcoin-native gaming mechanics and developer SDK.

**Version:** 0.1.0-alpha  
**License:** MIT

The browser edition includes provable odds, HMAC-SHA256 verifiable randomness, sanitized Lightning micropayment events, local leaderboards, and embeddable JavaScript APIs.

It is wallet-agnostic and stores no Bitcoin secrets.

Deploy directly into `/projects/software/bitgaming/`.

`logo.png` is intentionally omitted until final artwork is supplied.
