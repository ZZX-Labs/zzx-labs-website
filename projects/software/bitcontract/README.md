# BitContract

Bitcoin smart-contract template generator.

**Version:** 0.1.0-alpha  
**License:** MIT

Browser functionality includes multisig descriptor templates, CLTV/CSV script-policy templates, HTLC templates, DLC agreement metadata, static validation tests, and JSON export.

No private-key custody, signing, funding, or broadcasting is performed.

Deploy directly into `/projects/software/bitcontract/`.

`logo.png` is intentionally omitted until final artwork is supplied.
