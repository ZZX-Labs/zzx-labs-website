# BitBurn

Scenario-based Bitcoin lost-supply modeling.

**Version:** 0.1.0-alpha  
**License:** MIT

BitBurn does not claim that old coins are definitely lost. The browser model accepts aggregate UTXO age buckets and applies a transparent logistic loss-probability curve with inactivity and transaction-pattern confidence modifiers.

The illustrative dataset is synthetic only.

Deploy directly into `/projects/software/bitburn/`. `logo.png` is intentionally not bundled.
