# VidTag

`/projects/software/vidtag/`

VidTag is a local-first video metadata tagging and cataloging tool for organizing video libraries, extracting technical metadata, assigning tags and notes, generating poster frames, computing file hashes, and exporting portable JSON/CSV sidecars for archival workflows.

The browser workbench supports explicit local video ingestion, SHA-256 hashing, video playback/technical metadata, freeform tags, notes, ratings, poster-frame capture, catalog search, and JSON/CSV/per-video sidecar export.

The native helper uses `ffprobe` for technical metadata and computes SHA-256 locally.
