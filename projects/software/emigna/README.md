# EMIGNA Encryption System

Programmable rotor-based encryption/encoding research system with SHA3-256 layers and modular rotor definitions.

**Version:** 0.1.0-alpha  
**License:** MIT

The browser edition implements deterministic 256-byte rotor permutations, stepping, reversible transforms, SHA3-256, custom rotor JSON validation/import/export, and CPU benchmarking. CUDA/GPU acceleration remains a native architecture feature.

Rotor-only cryptography is experimental and is not presented as a substitute for standardized authenticated encryption.

Deploy directly into `/projects/software/emigna/`.

`logo.png` is intentionally omitted until final artwork is supplied.
