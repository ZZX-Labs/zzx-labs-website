# SpeciedexNet

`/projects/software/speciedexnet/`

SpeciedexNet is a federated P2P knowledge network for distributed biodiversity research. It enables signed, versioned contributions, encrypted field communications, and conservation telemetry linked to market incentives.

The browser companion models federated peers, generates in-memory ECDSA P-256 signing keys, creates signed/versioned biodiversity contributions, encrypts local field-message packages with AES-GCM, records Bitcoin/Lightning incentive metadata, and exports a network snapshot.

It does not open P2P connections, export private signing keys, or execute Bitcoin/Lightning payments.
