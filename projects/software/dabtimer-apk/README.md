# Dab Timer (APK)

Browser companion for the Android Dab Timer project. Implements the core mobile timer flow, visual phase cues, optional vibration hooks, and offline presets.

The manifest-declared APK path is `/projects/software/dabtimer-apk/dabtimer-apk.apk`, but no APK binary is fabricated or bundled here.

Deploy directly into `/projects/software/dabtimer-apk/`.
