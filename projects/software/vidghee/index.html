VidGhee

VidGhee is a PyQt5 video-to-GIF and frame extraction GUI that supports trimming, thumbnailing, meme capture, and batch export workflows.

Unlike a placeholder converter page, this browser build includes its own GIF89a encoder using a fixed 3-3-2 color palette, so captured frames can be exported as an actual animated GIF without a server.
