# VidGhee

`/projects/software/vidghee/`

VidGhee is a PyQt5 video-to-GIF and frame extraction GUI that supports trimming, thumbnailing, meme capture, and batch export workflows.

The browser build provides local video loading, seeking, single-frame capture, range capture at configurable FPS, scaling, thumbnail previews, PNG frame export, thumbnail-sheet export, and actual animated GIF89a generation using the included `gif-encoder.js`.

Native PyQt5/FFmpeg/Pillow remains the preferred implementation for high-quality palettes, long clips, and batch jobs.
