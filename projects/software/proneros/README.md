# PRONER-OS
`/projects/software/proneros/`

Hardened sandboxed desktop operating profile for adult media workflows. Implements isolated network stacks, encrypted containers, and privacy-oriented utilities for creative professionals and researchers.

The web companion is a hardening/profile planner for isolated adult-media workflows. It models VM isolation, QEMU/KVM, Firejail, encrypted storage, Tor/WireGuard profiles, outbound-default-deny policy, removable-media handling, snapshot reset, and host integration.

The original manifest lists Docker among dependencies, but this web/reference build intentionally does not use Docker.
