# Delta Dharma Theory

Browser research companion for the internal DDT project.

The model treats “dharma mass” as an abstract user-defined state variable and supports deterministic seeded simulation, Monte Carlo exploration, retention sweeps, Canvas visualization, and reproducible JSON/CSV export.

The output is a consequence of assumptions. It is not presented as a physical measurement of souls, reincarnation, or consciousness.
