# BitCasino

BTC-native casino-engine research workbench.

**Version:** 0.1.0-alpha  
**License:** MIT

The browser edition implements local game plugins, commit/reveal fairness, deterministic HMAC-SHA256 outcomes, simulated bankroll limits, reserve metadata, Lightning settlement-provider hooks, and player-side proof verification.

It uses simulated credits and does not accept wagers or custody funds.

Deploy directly into `/projects/software/bitcasino/`.

`logo.png` is intentionally omitted until final artwork is supplied.
