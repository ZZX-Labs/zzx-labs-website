# OwnMap

`/projects/software/ownmap/`

OwnMap is a decentralized geospatial intelligence and property operations platform integrating mapping, CRM, legal workflows, escrow systems, and field data collection with offline-first capabilities.

## Browser implementation

OwnMap's web companion provides:

- point GeoJSON import/export;
- local property records;
- a dependency-free map/canvas plot;
- CRM contacts;
- legal/due-diligence workflow records;
- deadlines/statuses;
- escrow-state/reference records;
- complete workspace JSON export.

The browser does not custody money, Bitcoin, or escrow funds.

The manifest-native application uses Python, PyQt5, SQLite, requests, Qt/PyQt5 for persistent offline-first property operations.
