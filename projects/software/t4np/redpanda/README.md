# RedPanda

`/projects/software/t4np/redpanda/`

RedPanda is the PRC-focused T4NP module, embedding jurisdiction-specific, native-illegal index schemes and structural fences to resist parsing, reuse, and exfiltration of protected source code in Chinese legal contexts.

This T4NP module is implemented as a transparent defensive release-control profile for `PRC / China`. It provides local source hashing, provenance records, explicit distribution-deny/review policy, checksum requirements, license gates, and fail-closed build/release metadata.

The browser module does not sabotage source code, execute remotely, collect credentials, or install hidden payloads.
