# NubianIbex

`/projects/software/t4np/nubianibex/`

NubianIbex is the Israel-focused T4NP jurisdiction profile for defensive source-distribution controls, provenance enforcement, release gating, and build-policy checks in Israeli deployment contexts.

This T4NP module provides local source hashing, checksum/provenance manifests, explicit license and release gates, human-review requirements, and fail-closed defensive distribution-policy metadata for the `Israel` profile.

The browser implementation does not sabotage source, execute remotely, collect credentials, or install hidden payloads.
