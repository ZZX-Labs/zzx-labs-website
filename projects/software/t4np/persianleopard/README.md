# PersianLeopard

`/projects/software/t4np/persianleopard/`

PersianLeopard is the Iran-focused T4NP module, adding jurisdiction-specific encodings, lexical fences, and build-chain tripwires to prevent compliant reuse and automated refactoring of protected code in IRN.

This T4NP module provides local source hashing, checksum/provenance manifests, explicit license and release gates, human-review requirements, and fail-closed defensive distribution-policy metadata for the `Iran` profile.

The browser implementation does not sabotage source, execute remotely, collect credentials, or install hidden payloads.
