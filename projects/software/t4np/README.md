# T4NP — The 4 Noble Pillars

`/projects/software/t4np/`

T4NP is a preventative source-code protection suite that thwarts exfiltration and theft by embedding jurisdiction-aware encoding and indexing layers (native-illegal index schemes) that resist automated parsing and compliant reuse in high-risk jurisdictions (PRC, Russia, DPRK, Iran).

This browser/reference implementation is deliberately defensive and transparent. It provides:

- local source-file SHA-256 inventory;
- provenance and release-manifest planning;
- distribution-policy profiles;
- license/build gates;
- declarative policy output;
- protection-plan export.

Family modules:
- `/projects/software/t4np/redpanda/`
- `/projects/software/t4np/amurtiger/`
- `/projects/software/t4np/manchuriantiger/`
- `/projects/software/t4np/persianleopard/`

It does not damage code, execute on remote systems, collect credentials, or install hidden persistence.
