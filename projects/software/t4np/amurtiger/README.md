# AmurTiger

`/projects/software/t4np/amurtiger/`

AmurTiger is the Russia-focused T4NP module, applying jurisdiction-tuned lexical and structural encodings that frustrate automated tooling, redistribution, and compliant reuse within Russian legal and linguistic environments.

This T4NP module is implemented as a transparent defensive release-control profile for `Russia`. It provides local source hashing, provenance records, explicit distribution-deny/review policy, checksum requirements, license gates, and fail-closed build/release metadata.

The browser module does not sabotage source code, execute remotely, collect credentials, or install hidden payloads.
