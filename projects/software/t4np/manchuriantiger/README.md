# ManchurianTiger

`/projects/software/t4np/manchuriantiger/`

ManchurianTiger is the DPRK-focused T4NP module, introducing native-illegal indexing and codepath obfuscation rules that deter analysis, compilation, and compliant reuse of protected code in North Korean contexts.

This T4NP module is implemented as a transparent defensive release-control profile for `DPRK / North Korea`. It provides local source hashing, provenance records, explicit distribution-deny/review policy, checksum requirements, license gates, and fail-closed build/release metadata.

The browser module does not sabotage source code, execute remotely, collect credentials, or install hidden payloads.
