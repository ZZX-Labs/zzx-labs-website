PROJECT

        
Overview

        

          4⁴ is a guided respiration timer built around the canonical four-phase box-breathing
          sequence: inhale, hold, exhale, hold. The browser port mirrors the native application's
          timing, visual guidance, and cueing without requiring installation.

LOCAL-FIRST

      
Browser Privacy Boundary

      

        4⁴ does not need a network connection for its breathing timer. Settings and statistics
        are stored only in the browser's local storage. Audio, haptic, speech, fullscreen, and
        wake-lock features use permissioned browser APIs.
