# SpeciedexExplorer

`/projects/software/speciedexexplorer/`

SpeciedexExplorer is a real-time explorer for Speciedex taxonomy chains, lineage trees, habitat data, and extinction records, with user dashboards, API, and integrated social/email sharing.

The browser companion provides local Speciedex dataset import, search, lineage-tree views, habitat/status summaries, extinction labels, share-text construction, and snapshot export.

Static habitat pins are explicitly illustrative rather than live occurrence data.
