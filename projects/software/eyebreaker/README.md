# EyeBreaker

Functional browser adaptation of the offline EyeBreaker screen-time interruption system.

Implements work/break cycles, optional browser notifications, break-compliance logging, subjective eye/focus fatigue check-ins, trend charts, and JSON/CSV export. Browser-session data stays in memory unless explicitly exported.

This is a wellness/productivity tool, not a medical diagnostic system.

Deploy directly into `/projects/software/eyebreaker/`.

`logo.png` is intentionally omitted.
