# Parallel Explorer

`/projects/software/parallel-explorer/`

Parallel Explorer is a high-performance AI-assisted file forensics and search engine that performs parallel directory scans, schema-aware metadata extraction, and contextual query matching across large datasets.

The browser companion provides explicitly user-selected directory indexing, asynchronous worker-style file inspection, SHA-256, text previews, JSON top-level schema keys, simple contextual token matching, exact duplicate grouping, and index export.

The static page does not scan remote systems or arbitrary host paths.

Native dependencies: `python3, numpy, sqlalchemy, pandas, pyqt5, torch, requests`.

Version: `0.3.0-alpha`
