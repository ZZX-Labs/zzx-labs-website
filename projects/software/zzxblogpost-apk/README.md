# zzxblogpost (APK)

`/projects/software/zzxblogpost-apk/`

Native Android APK companion for zzxblogpost enabling offline drafting, reading, and controlled export of posts and attachments.

This deployment includes the standardized browser/mobile companion plus actual Kotlin/Android source under `android-source/`. The native source provides offline draft persistence and controlled Android share/export.

The catalog download route remains `/projects/software/zzxblogpost-apk/zzxblogpost-apk.apk`, but no fabricated APK binary is included.
