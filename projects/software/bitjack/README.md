# BitJack

Provably-fair blackjack engine under the BitCasino stack.

**Version:** 0.1.0-alpha  
**License:** MIT

The browser edition includes local blackjack gameplay, deterministic HMAC-SHA256 deck shuffling, seed commitments, complete hand-proof export, player-side deck verification, and a non-custodial Lightning settlement-provider hook.

It uses simulation credits and does not accept wagers or custody funds.

Deploy directly into `/projects/software/bitjack/`.

`logo.png` is intentionally omitted until final artwork is supplied.
