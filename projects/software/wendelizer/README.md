# Wendelizer

`/projects/software/wendelizer/`

Voice FX transformer tuned to Wendel (of Frisky Dingo)-like vocal formants; supports live and recorded pipelines with adjustable synthesis filters.

The browser implementation performs real microphone processing with a three-formant peaking-filter chain, low-pass filtering, compression, waveshaping, level metering, editable presets, microphone recording, and profile export.

The preset is a stylized voice effect and does not perform identity voice cloning.
