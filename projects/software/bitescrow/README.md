# BitEscrow

Milestone-based Bitcoin multisig escrow policy and arbitration framework.

**Version:** 0.1.0-alpha  
**License:** MIT

The browser edition models N-of-M authorization, milestones, arbitration states, evidence metadata, SHA-256 evidence hashes, and PBKDF2/AES-256-GCM encrypted evidence-pack export.

It does not hold private keys or sign/broadcast Bitcoin transactions.

Deploy directly into `/projects/software/bitescrow/`.

`logo.png` is intentionally omitted until final artwork is supplied.
