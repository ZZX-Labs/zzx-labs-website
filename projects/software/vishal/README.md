# Vishal

`/projects/software/vishal/`

Vishal is a Python audiovisual session ecosystem focused on tranquility and relaxation, combining ambient visuals, soundscapes, and session scripting in a PyQt5 GUI.

The browser build is a functional audiovisual session engine with editable timed phases, breath/mandala/aurora/rain visual modes, synthesized drone/rain Web Audio layers, live session timers, visual PNG snapshots, presets, and session JSON export.

It makes no medical or therapeutic efficacy claims.
