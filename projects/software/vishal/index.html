Vishal

Vishal is a Python audiovisual session ecosystem focused on tranquility and relaxation, combining ambient visuals, soundscapes, and session scripting in a PyQt5 GUI.

Vishal is a relaxation/session tool, not a medical treatment. The browser build synthesizes visuals and simple local Web Audio soundscapes without sending session data anywhere.
