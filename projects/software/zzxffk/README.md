# ZZX-FFK

`/projects/software/zzxffk/`

Forensic Field Kit (FFK) — a modular cross-platform forensic analysis suite for disk, memory, and network inspection. Includes both CLI and PyQt5 GUI interfaces with exportable audit trails.

The web field kit provides local evidence ingestion, SHA-256 hashing, first-128-byte hex inspection, timestamps, case/audit logging, process-snapshot JSON import, PCAP header metadata inspection, timeline generation, and read-only case export.

The included native Python helper performs read-only file hashing/inventory and optional local process inventory with `psutil`. It does not modify evidence or execute remote actions.
