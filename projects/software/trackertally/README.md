# TrackerTally

`/projects/software/trackertally/`

Privacy-first behavioral tracking system for consumables and habits with time-based analytics and offline-first logs designed for reduction workflows and long-term self-audit.

The browser implementation provides local habit/consumable logging, filtering, deletion, 14-day aggregate visualization, JSON/CSV export, JSON import, and browser-local persistence.

No cloud upload or medical interpretation is performed.
