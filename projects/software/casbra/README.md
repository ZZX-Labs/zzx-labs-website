# CasBra

Probabilistic card/game-state research workbench.

**Version:** 0.1.0-alpha  
**License:** MIT

The browser edition implements transparent card-state validation, Hold'em Monte Carlo equity, weighted opponent ranges, local image/video preview, annotation import, and session export. Native OpenCV/TensorFlow/CUDA remain the full visual-inference stack.

Deploy directly into `/projects/software/casbra/`.

`logo.png` is intentionally omitted until final artwork is supplied.
