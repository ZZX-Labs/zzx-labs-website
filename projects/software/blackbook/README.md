# BlackBook

Encrypted private contact and profile management suite.

**Version:** 0.1.0-alpha  
**License:** MIT  
**Manifest note:** ADULT – NSFW!*

The browser edition stores profiles, private notes, consent/preferences metadata, medical records, relationship links, and external PGP/GPG identity fingerprints inside a PBKDF2-HMAC-SHA256 + AES-256-GCM encrypted local vault.

No server sync is performed. Private cryptographic keys are not stored.

Deploy directly into `/projects/software/blackbook/`.

`logo.png` is intentionally omitted until final artwork is supplied.
