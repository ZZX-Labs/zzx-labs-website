# BitOnion

Bitcoin Core / Knots privacy-routing profile and gateway planner.

**Version:** 0.1.0-alpha  
**License:** MIT

The browser edition builds Tor/I2P/VPN route profiles, generates bitcoin.conf privacy fragments, evaluates sanitized health JSON, and produces monitoring checklists.

It does not execute host shell commands, start VPN/Tor/I2P services, run nmap, or capture packets.

Deploy directly into:

```text
/projects/software/bitonion/
```

`logo.png` is intentionally not included.
