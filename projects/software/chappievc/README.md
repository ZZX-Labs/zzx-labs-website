# ChappieVC (Voice Changer)

**INTERNAL – Not for public distribution.**

Real-time robot/mech/droid voice-effects workbench.

**Version:** 0.1.0-alpha  
**License:** MIT

The browser edition provides microphone/file input, distortion, band-pass spectral shaping, ring modulation, delay, wet/dry mix, spectrum visualization, generic robot/mech/droid/glitch presets, Web MIDI mapping, and preset export. It does not implement voice cloning or specific-person impersonation.

Native PyTorch/Torchaudio/FFmpeg/PyAudio/sounddevice remain the full low-latency neural/audio backend.

Deploy directly into `/projects/software/chappievc/`.

`logo.png` is intentionally omitted so existing artwork is not overwritten.
