# FieldRecorder (APK)

Browser companion for the native Android/Kotlin FieldRecorder.

Provides a mobile recording flow, vibration cues where available, local recording metadata with SHA-256 fingerprints, and explicit backup-plan export. Nothing is uploaded automatically.

The manifest-declared APK path is `/projects/software/fieldrecorder-apk/fieldrecorder-apk.apk`; no APK binary is fabricated or bundled here.

Deploy directly into `/projects/software/fieldrecorder-apk/`.
