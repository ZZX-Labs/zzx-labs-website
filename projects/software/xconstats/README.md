# XConStats

`/projects/software/xconstats/`

Controller telemetry utility monitoring Xbox wireless controller charge, battery health, and session duration with predictive time-remaining analysis.

The browser workbench supports session timing, manual/authorized telemetry samples, discharge-rate estimation, time-remaining estimation, history graphs, Gamepad API discovery, optional WebHID device authorization, and telemetry export.

The included native helper enumerates Microsoft HID devices with `hidapi`. Battery decoding remains transport/controller-specific rather than being guessed.
