# Woise

`/projects/software/woise/`

White-noise generator and soundscape lab featuring filters, LFOs, MIDI control, and customizable preset packs for audio environments and focus tools.

The browser implementation generates white, pink, and brown noise; routes it through configurable filters and gain modulation; renders a live spectrum; supports LFO controls, preset management, optional Web MIDI CC mapping, and offline WAV generation.
