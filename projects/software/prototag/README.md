# ProtoTag
`/projects/software/prototag/`

ProtoTag is a prototype video tagging environment for designing and testing MetaTagDB schemas, metadata rules, and user workflows in both CLI and PyQt5 GUI modes.

The browser companion provides MetaTagDB schema design, typed fields, required/optional flags, simple tag rules, sample-record validation, rule application, and JSON export.
