# PyTimecard (APK)

`/projects/software/pytimecard-apk/`

Native Android APK companion for PyTimecard providing mobile timecard entry, shift logs, and offline-first export.

The browser/reference companion supports mobile-style clock-in/clock-out, manual shift entry, local session history, and offline JSON export.

It does not fabricate an APK binary. The native project uses Android SDK and Kotlin.

Manifest download path: `/projects/software/pytimecard-apk/pytimecard-apk.apk`
