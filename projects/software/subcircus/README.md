# SubCircus

`/projects/software/subcircus/`

SubCircus is an EDM live-streaming platform for DJs offering broadcast scheduling, chat, VOD clipping, and Bitcoin microtransaction tipping via Lightning Network integration.

The browser companion provides broadcast scheduling, local chat simulation/moderation state, local video playback with IN/OUT VOD clip planning, Lightning-tip ledger events, and complete workspace export.

Live ingest, FFmpeg transcoding, chat transport, persistence, and Lightning settlement belong to the native Flask/SQLAlchemy/FFmpeg/LND deployment.
