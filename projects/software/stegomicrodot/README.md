# StegoMicrodot

`/projects/software/stegomicrodot/`

StegoMicrodot is a high-density microdot and halftone steganography toolkit supporting printer calibration, embedded ciphertext encoding, and multi-layer decoding.

The browser companion provides local AES-GCM encryption, binary microdot rendering, PNG export, package JSON export, local decryption, and a printer-density calibration strip.

It does not transmit payloads or automate covert network delivery.
