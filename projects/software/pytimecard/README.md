# PyTimecard

`/projects/software/pytimecard/`

Time tracking, pay estimation, and labor analytics system for contractors and distributed teams. Focuses on auditable logs, offline-first records, and exportable summaries.

The browser companion provides shift entry, breaks, project/client labels, hourly rates, simple daily overtime modeling, hours/gross estimates, auditable local records, and JSON/CSV export.

The pay calculations are estimates only and do not implement jurisdiction-specific wage, tax, or payroll rules.

Native dependencies: `python3, pyqt5`.

Version: `0.9.0-beta`
