The project manifest requests 12, 16, 24, and 32-word phrases. The browser generator implements those lengths as unbiased selection from an imported wordlist and does not silently claim every custom length is BIP39-compatible. The native `bip-utils` implementation should enforce whichever wallet/mnemonic specification the project adopts.
