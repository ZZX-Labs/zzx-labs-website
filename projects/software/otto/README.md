# otto

`/projects/software/otto/`

otto (Operator Tools & Task Orchestrator) is a high-automation video ripper and downloader system for capturing online streams, managing task queues, and integrating with local archival storage workflows.

**INTERNAL – Not for public distribution.**

The browser companion provides authorized-source task planning, queue management, status tracking, output templates, optional FFmpeg segment planning, inspectable yt-dlp command generation, and JSON queue export.

It does not execute downloads in the browser.

Use only for content you own, are licensed to archive, or are otherwise authorized to capture.

Native stack: `python3, yt-dlp, ffmpeg, requests, sqlalchemy`.

Version: `0.3.0-alpha`
