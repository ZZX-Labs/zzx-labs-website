# BitLegal

Legal-agreement automation with Bitcoin/Lightning action metadata, signature-binding records, notarization hashes, and BitEscrow arbitration references.

**Version:** 0.1.0-alpha  
**License:** MIT

The browser edition is an automation/evidence-binding tool, not legal advice. It does not determine enforceability.

Deploy directly into `/projects/software/bitlegal/`.

`logo.png` is intentionally omitted until final artwork is supplied.
