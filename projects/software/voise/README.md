# Voise

`/projects/software/voise/`

Real-time voice changer and vocoder supporting STT↔TTS routing, FX chains, and high-quality multitrack exports for live or studio use.

The browser implementation provides real-time microphone capture, Web Audio high/low-pass filtering, distortion, delay/echo, ring modulation, live level metering, generic STT/TTS routing where supported, microphone recording, and native FX-chain export.

It is generic voice FX tooling and does not perform specific-person voice cloning.
