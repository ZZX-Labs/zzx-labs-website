# BitBetting

Provably-fair Bitcoin betting protocol research workbench.

**Version:** 0.1.0-alpha  
**License:** MIT

The browser edition demonstrates commit/reveal fairness, deterministic HMAC-SHA256 outcomes, offline verification, prediction-market metadata, BitContract/on-chain proof references, and a non-custodial Lightning settlement-provider hook.

It does not take wagers, hold funds, or contain Lightning wallet credentials.

Deploy directly into `/projects/software/bitbetting/`.

`logo.png` is intentionally omitted until final artwork is supplied.
