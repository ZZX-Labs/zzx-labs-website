SECURITY MODEL

Public Bitcoin data is supplemental entropy/audit material, not a secret. Key-grade randomness comes from crypto.getRandomValues(); public chain data is mixed in, never trusted as the sole seed.

QUICK BIAS DIAGNOSTICS
Entropy Tests
Run byte-frequency, monobit, Shannon entropy, and serial-correlation diagnostics against generated output.




These quick diagnostics do not replace NIST STS, Dieharder, PractRand, hardware certification, or a formal entropy-source assessment.



REPRODUCIBLE RECORD
Audit Log
Export public collection material, hashes, test results, and seed fingerprints. Secret CSPRNG contributions are never written into the audit log.
