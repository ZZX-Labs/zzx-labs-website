# ZZX-TAS

`/projects/software/zzxtas/`

ZZX-TAS (Termux Android Suite) is an Android/Termux-native collection of ZZX-Labs tools, wrappers, and deployment scripts for running Bitcoin, AI, media, and security utilities directly on mobile devices.

The browser workbench builds Termux package plans, reviewable `pkg install` commands, backup/checksum commands, local wrapper templates, and environment manifests. It does not auto-execute commands or embed credentials. A conservative interactive Termux bootstrap script is included.
