FIREFOX WEBEXTENSION // TAB BACKUP // SESSION EXPORT

URLScraper

URLScraper is a Firefox extension that backs up all open tabs/URLs to TXT, CSV, JSON, or SQL with filters, de-duplication, tagging, and session-friendly exports.

This deploy includes an actual Firefox WebExtension source under addon/ in addition to the website workbench. The website itself cannot query browser tabs because ordinary pages do not receive the extension's tabs permission.
