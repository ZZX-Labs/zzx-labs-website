# BitContractor

Hybrid legal / on-chain Bitcoin contract authoring and publishing suite.

**Version:** 0.1.0-alpha  
**License:** MIT

The browser edition includes templates, local version snapshots, SHA-256 version identifiers, line-based redlining, signature-binding records, notarization hashes, review metadata, BitEscrow references, JSON/text export, and a dependency-free local PDF writer.

Deploy directly into `/projects/software/bitcontractor/`.

The page is contract-automation software, not legal advice. `logo.png` is intentionally omitted until final artwork is supplied.
