# ZZX-DES

`/projects/software/zzxdes/`

Directory Explorer System (DES) — a hierarchical file and data browser featuring tagging, previews, metadata search, and secure bulk operations for archival data management.

The browser workbench provides explicit directory selection, hierarchical-path indexing, metadata search, media/text previews, tags, SHA-256 hashing, tag/kind filters, reviewable rename/move/archive bulk-operation plans, and metadata index export.

Browser bulk actions are plans only; no file is silently moved or renamed. A native Python indexer is included under `native/`.
