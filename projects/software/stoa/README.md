# STOA

`/projects/software/stoa/`

STOA (Savings Timelock-Out Accounts) provides Bitcoin policy templates, locking scripts, and auditable dashboards for delayed spending and escrow-based time-locked savings instruments.

The browser companion builds CLTV/CSV timelock policy records, amount/purpose/recovery metadata, inspectable script templates, lock-state summaries, and JSON exports.

The page never requests private keys, seed phrases, wallet passwords, macaroons, or RPC credentials and does not create signed or broadcast transactions.
