GSKs (Glyph Sprite Keys)

GSK defines a custom cryptographic key format derived from SHA3-256 and RIPEMD160 with a lowercase Base32 encoding, excluding ambiguous glyphs. Each key includes an extended checksum and prefix structure for unique, human-readable, and error-resistant identifiers used across ZZX-Labs encryption systems.
