# Bitcoin-Tully

Bitcoin Core / Knots wallet-finding and forensic-backup tooling.

**Version:** 0.1.0-alpha  
**License:** MIT  
**Native platform:** Windows / cmder

The browser edition is intentionally read-only: it inventories user-selected files/directories, classifies common wallet artifacts, hashes them with SHA-256, detects duplicates, stores case notes locally, and exports forensic backup manifests.

Deploy directly into `/projects/software/bitcoin-tully/`.

`logo.png` is intentionally omitted until final artwork is supplied.
