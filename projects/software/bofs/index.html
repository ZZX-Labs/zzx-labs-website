VOLUME MODEL
Format
BOFS alpha volume
- volume descriptor: label, archive id, profile, created time
- file table: path, byte length, SHA-256, sequence id
- sequence: fixed-size data frames + XOR parity groups
- optical carrier: BQRES binary symbol frame
- ordering: volume index -> file sequence -> frame index
- redundancy: optional duplicate sequence copies
- recovery: one missing data frame per parity group
- ISO-oriented profile: records an ISO volume label / file table intent only;
  this browser reference does not construct an ISO-9660 binary image.
