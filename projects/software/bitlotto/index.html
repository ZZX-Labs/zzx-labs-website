Capabilities

AUDIT ENGINE ONLY

This web build demonstrates commitments and deterministic drawings. It does not collect money, custody funds, sell tickets, or settle wagers.

ESCROW-STYLE COMMITMENTS

Tickets

Create deterministic ticket commitments from participant label, chosen numbers, and a private nonce retained by the participant.






BITCOIN BLOCK HASH
Block Anchor
Enter a known block hash manually or fetch one from a configured Esplora endpoint.










PROVABLY REPLAYABLE DRAW
Draw
Combine the block hash, sorted ticket commitments, and draw parameters into a deterministic seed.









INDEPENDENT REPLAY
Verify
Paste an archived draw JSON and replay it entirely offline.



LONG-TERM AUDIT RECORD
Archive
Export tickets, commitments, anchor, seed derivation inputs, and result in one reproducible JSON record.
