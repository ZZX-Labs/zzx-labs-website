# BitLotto

Deterministic, replayable draw engine anchored to Bitcoin block hashes.

**Version:** 0.3.0-alpha  
**License:** MIT

The browser edition supports ticket commitments, participant nonces, manual or Esplora-fetched block anchors, deterministic HMAC-SHA256 drawings, offline replay verification, and JSON archival.

This static build does not sell tickets, collect funds, custody Bitcoin, or settle wagers.

Deploy directly into:

```text
/projects/software/bitlotto/
```

`logo.png` is intentionally not included.
