# Bitcoin-Mined

Minimal Bitcoin circulation and emission tracker.

**Version:** 0.1.0-alpha  
**License:** MIT

The browser edition calculates subsidy-only issuance from block height and can optionally fetch live height from an Esplora/mempool API.

“Issued BTC” means consensus block-subsidy issuance. It does not subtract lost/burned/unspendable coins and does not count transaction fees as new issuance.

Deploy directly into:

```text
/projects/software/bitcoin-mined/
```

`logo.png` is intentionally omitted until final artwork is supplied.
