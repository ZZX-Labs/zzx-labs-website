# BitAge

Empirical Bitcoin block-time interval measurement and visualization.

**Version:** 0.2.0-alpha  
**License:** MIT

The browser edition supports Esplora sampling, an optional Bitcoin Core provider adapter, interval computation, rolling statistics, quantiles, visualization, and JSON/CSV export.

Deploy directly into:

```text
/projects/software/bitage/
```

The archive does not include `logo.png`; an existing deployment logo is left untouched.
