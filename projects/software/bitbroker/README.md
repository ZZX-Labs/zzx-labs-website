# BitBroker

Programmable Bitcoin order-router and market-microstructure research toolkit.

**Version:** 0.2.0-beta  
**License:** MIT

The browser edition models venue quotes, fees, depth, latency and slippage; splits simulated routes across venues; creates TWAP accumulation plans; calculates portfolio rebalancing; and exports research plans.

It does not accept exchange API secrets or submit live orders. Native CCXT execution remains outside the static page.

Deploy directly into `/projects/software/bitbroker/`.

`logo.png` is intentionally omitted until final artwork is supplied.
