# GP: (GPT PDA)

Functional browser companion for the GP assistant suite.

It provides text and multimodal job queues, Web Speech TTS/STT hooks where supported, user-controlled emotional-state modeling, plugin manifests, and session export. Actual PyTorch/Transformers/Diffusers execution remains in native/model adapters.

Adult mode is treated as adults-only and consensual; the browser page does not provide identity cloning or non-consensual sexual-content tooling.

Deploy directly into `/projects/software/gp/`.

`logo.png` is intentionally omitted.
