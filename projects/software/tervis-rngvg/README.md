# TerVIS-RNGvG

`/projects/software/tervis-rngvg/`

TerVIS-RNGvG (Randomized Next-Gen Video Generator) generates synthetic terrestrial video datasets via augmentation, frame interpolation, and noise modeling for AI training and testing pipelines.

The browser companion provides seeded procedural terrestrial scenes, animation, configurable motion/daylight/noise, normalized synthetic object labels, PNG export, recipe export, and WebM canvas capture where supported.
