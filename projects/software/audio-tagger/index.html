LOCAL-FIRST

      
Catalog Safety Boundary

      

        Raw audio files are processed in-browser and are not uploaded by the supplied page.
        IndexedDB stores metadata, fingerprints, and catalog edits only. Recognition can use
        a network only if an explicit user-supplied provider chooses to do so.
