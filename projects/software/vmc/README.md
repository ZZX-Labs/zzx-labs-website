# Vipassana Meditation Console (VMC)

`/projects/software/vmc/`

Dedicated meditation system integrating guided sessions, breathing protocols, and sensory feedback across software and embedded hardware platforms.

The browser console provides timed Vipassana/Anapanasati/open-awareness/walking sessions, selectable breathing protocols, cue tones, lap/marker logging, hardware-profile selection, and session export.

The package also includes a shared `hardware/protocol.json` contract for ESP32/LilyGO and Arduino Nano/Micro/Mini/Uno R4 variants.
