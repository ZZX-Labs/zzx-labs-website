Vipassana Meditation Console (VMC)

Dedicated meditation system integrating guided sessions, breathing protocols, and sensory feedback across software and embedded hardware platforms.

This build incorporates the broader VMC hardware-family concept instead of reducing VMC to a timer-only page. It includes a shared embedded serial/event protocol for ESP32 and Arduino-class variants.
