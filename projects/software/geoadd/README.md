# GeoAdd

Functional browser implementation of a reversible, precision-variable geo-address shortcode.

The web format is `ga:<precision>:<code>` using a geohash-style base32 subdivision. It supports encode/decode, bounding boxes, precision comparison, batch CSV encoding, and OpenStreetMap area links.

Deploy directly into `/projects/software/geoadd/`.

`logo.png` is intentionally omitted.
