# MantraBox

`/projects/software/mantrabox/`

MantraBox is a TTS mantra synthesizer and looper that supports tempo control, layering, and session exports with visual feedback and soundscape synchronization for meditation and ritual use.

## Browser workbench

The page provides:

- mantra/phrase editor;
- BPM and beats-per-repetition timing;
- browser TTS through Web Speech;
- speech rate and pitch controls;
- loop scheduling;
- repetition counter;
- visual pulse cue;
- simple Web Audio drone/noise soundscapes;
- JSON session export.

Browser TTS voices depend on the operating system and browser. The native project manifest specifies PyQt5, gTTS, PyAudio, and FFmpeg for the full application.
