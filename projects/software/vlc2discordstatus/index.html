VLC STATUS // DISCORD RICH PRESENCE // LOCAL BRIDGE

VLC2DiscordStatus

Real-time integration between VLC media playback and Discord Rich Presence displaying track metadata, playback time, and media state.

This deploy includes an actual native Python bridge under native/. The browser workbench previews and exports presence payloads; it does not falsely claim a web page can speak to Discord's local IPC socket.

The helper polls VLC's loopback HTTP endpoint with requests, reads the VLC password and Discord client ID only from environment variables, and uses optional pypresence for Discord IPC. Without RPC support it prints JSON previews instead.
