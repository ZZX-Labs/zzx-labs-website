# zzxblogpost

`/projects/software/zzxblogpost/`

Offline-first academic and technical publishing toolchain for ZZX-Labs posts, bulletins, disclosures, and research notes, optimized for controlled release and reproducible builds.

Functional browser tooling includes Markdown drafting, live preview, metadata/front-matter fields, local attachment hashing, deterministic release metadata, SHA-256 content IDs, Markdown/HTML/release JSON export, and controlled-release packaging.

A native Python release builder is included under `native/`.
