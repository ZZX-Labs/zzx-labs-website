# CyberConcubine

Privacy-first adult partnership coordination workbench.

Supports 1+N relationship coordination, time/connection balance metrics, dates/trips/scenes/sessions, user-entered astrology and cycle context, consent/boundary reminders, agreement templates, and PBKDF2-HMAC-SHA256 + AES-256-GCM encrypted project export/import.

Working state remains in memory and is not sent to a server. Persistence is explicit through encrypted export.

This is a coordination tool, not a mechanism for entitlement, coercion, medical diagnosis, or legal advice.

Deploy directly into `/projects/software/cyberconcubine/`.
