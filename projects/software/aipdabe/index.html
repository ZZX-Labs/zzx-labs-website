READ-ONLY

      
Browser Security Boundary

      

        AIPDABE's web edition is an analysis interface. It does not request private keys,
        seed phrases, wallet passwords, or Bitcoin Core RPC credentials. Public API results
        and imported JSON are treated as untrusted data and rendered through text-safe DOM
        operations or JSON serialization.
