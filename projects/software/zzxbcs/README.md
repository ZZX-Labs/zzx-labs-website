# ZZX-BCS

`/projects/software/zzxbcs/`

ZZX-BCS (Billing & Compensation System) is an internal, private financial management system for ZZX-Labs used to track billing, compensation, retainers, expenses, budgets, and treasury flows across projects and personnel.

The browser implementation provides a local ledger for invoices, compensation, retainers, expenses, budgets, and treasury entries; project/personnel attribution; manual BTC reference values; status tracking; project summaries; local persistence; and JSON/CSV export.

It does not perform live pricing, tax calculations, custody, payroll compliance, or banking/payment operations.
