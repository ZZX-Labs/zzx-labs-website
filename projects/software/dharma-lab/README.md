# Dharma Lab

Functional browser research companion for contemplative timing, comfortable breath pacing, attention probes, simple analytics, toy simulations, and reproducible export.

The browser build intentionally excludes extreme breath-hold/hypoxia protocols and does not make clinical or spiritual efficacy claims.

**Manifest note:** INTERNAL – Not for public distribution.

Deploy directly into `/projects/software/dharma-lab/`.
