# Blinkee Visual Transport Protocol (BVTP)

Optical transport-layer reference implementation for Blinkee-based frame streams.

**Version:** 0.1.0-alpha  
**License:** MIT  
**Category:** protocol

The browser edition implements stream IDs, packet sequencing, PTS timing, packetization, deterministic loss/jitter simulation, jitter buffering, XOR parity recovery, optical Canvas playback, SHA-256 source verification, and transport-capture export.

Native OpenCV/FFmpeg remain responsible for real camera/video acquisition and decoding.

Deploy directly into `/projects/software/bvtp/`.

`logo.png` is intentionally omitted until final artwork is supplied.
