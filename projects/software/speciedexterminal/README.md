# SpeciedexTerminal

`/projects/software/speciedexterminal/`

SpeciedexTerminal provides command-line workflows for advanced taxonomy queries, batch processing, provider synchronization operations, exports, diagnostics, reports, archival tasks, and automation over generated Speciedex indexes and SQLite shards.

The web terminal is intentionally a local command parser over imported Speciedex records. Commands include `stats`, `find`, `show`, `lineage`, `kingdoms`, and `export`.

It never executes arbitrary host commands and does not run provider adapters directly.
