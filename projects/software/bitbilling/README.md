# BitBilling

Bitcoin-native offline-first billing and invoicing.

**Version:** 0.9.0-beta  
**License:** MIT

The browser edition includes invoice creation, local ledger persistence, payment records, due/open/partial/paid status, text invoices, JSON/CSV export, and an external per-invoice address-provider hook.

Private wallet derivation material never belongs in the browser.

Deploy directly into `/projects/software/bitbilling/`.

`logo.png` is intentionally omitted until final artwork is supplied.
