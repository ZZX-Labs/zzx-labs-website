# satperPerson

`/projects/software/spp/`

satperPerson calculates the real-time fair share of Bitcoin circulation per human being using live blockchain supply data and continuous world population modeling to visualize satoshi-per-person equality through time.

The browser companion computes BTC and satoshi share per person from user-entered Bitcoin supply and population values, optionally adjusts for an assumed lost-supply percentage, renders an illustrative projection, and exports calculation snapshots.

No live API data is fabricated in the static build.
