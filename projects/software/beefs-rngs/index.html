HASHED ENTROPY POOL
Entropy Collector
Mix user text, local files, and fresh Web Crypto bytes into a SHA-256 audit pool without modifying source files.
Drop Entropy Files
File bytes are hashed locally.



REPRODUCIBLE HMAC STREAM
Deterministic Stream
Generate an auditable byte stream using HMAC-SHA256(seed, counter || context). Same inputs reproduce the same output.



QUICK STATISTICAL DIAGNOSTICS
Bias Tests
Run monobit, byte-frequency chi-square, serial correlation, and runs diagnostics on pasted hex or the latest generated bytes.
These are lightweight diagnostics, not a substitute for full NIST STS, Dieharder, PractRand, or specialized hardware-RNG qualification.
