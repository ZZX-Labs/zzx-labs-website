# BitTrackIt

Watch-only Bitcoin transaction, address, balance, fee, alert, and portfolio tracker.

**Version:** 0.2.0-alpha  
**License:** MIT

The browser edition uses public Esplora/mempool data. It does not accept private keys, seed phrases, wallet passwords, RPC credentials, or exchange secrets.

Deploy directly into:

```text
/projects/software/bittrackit/
```

For privacy-sensitive monitoring, use your own Esplora/mempool-compatible endpoint.

`logo.png` is intentionally omitted until final artwork is supplied.
