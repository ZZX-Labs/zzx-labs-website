# Pay-to-Toll Protocol (PtTP)
`/projects/software/pttp/`

Pay-to-Toll Protocol (PtTP) defines Bitcoin-native tolling primitives for metered digital services, API calls, or time-bound access control using P2T contracts and dynamic rate scheduling.

The browser companion is a Bitcoin-only, noncustodial protocol simulator for service/resource toll contracts, metered pricing, Lightning/on-chain rail labels, contract commitments, explicit access-state transitions, and JSON export.

It does not create live invoices, sign or broadcast transactions, hold funds, or request private keys or wallet credentials.
