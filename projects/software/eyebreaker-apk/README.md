# EyeBreaker (APK)

Browser companion for the Android/Kotlin EyeBreaker app.

Implements the mobile timer flow, vibration hooks where available, compliance logs, and explicit synchronization JSON export. No data is uploaded automatically.

The manifest-declared APK path is `/projects/software/eyebreaker-apk/eyebreaker-apk.apk`; no APK binary is fabricated or bundled here.

Deploy directly into `/projects/software/eyebreaker-apk/`.
