# CDRC

Court DocRec Collector local corpus workbench.

**Version:** 0.1.0-alpha  
**License:** MIT

The browser edition ingests local text/metadata, normalizes court records, computes SHA-256 de-duplication hashes, performs local search, prepares rate-limited download queues, and exports JSON/JSONL. Native Python remains responsible for robust crawling, HTML parsing, PDF text extraction, and SQL persistence.

Use public or otherwise authorized court-document sources and respect access rules/rate limits.

Deploy directly into `/projects/software/cdrc/`.

`logo.png` is intentionally omitted so existing artwork is not overwritten.
