# CEES-Chirp

**INTERNAL – Not for public distribution.**

Acoustic data-transmission protocol workbench.

**Version:** 0.1.0-alpha  
**License:** MIT

The browser edition provides PBKDF2/AES-256-GCM authenticated payload envelopes, 12-bit symbol packing across 4096 symbol IDs, deterministic dual-channel phase/frequency mappings, stereo WAV synthesis, CRC-32 framing, and frame export/decryption.

The biological 4096-species sample corpus is not bundled; the web demo uses deterministic synthetic carriers.

Deploy directly into `/projects/software/cees-chirp/`.

`logo.png` is intentionally omitted so existing artwork is not overwritten.
