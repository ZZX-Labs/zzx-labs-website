# ZZX-DEX

`/projects/software/zzxdex/`

DecentralizedExchange research clone environment for Bitcoin-only peer-to-peer transactional data studies, running internal Lightning-based liquidity models.

The web research environment models synthetic Lightning peers, outbound liquidity, routing fees/reliability, peer offers, route construction, and Monte Carlo success/fee behavior. It never connects to LND, signs transactions, broadcasts payments, or requests wallet credentials.
