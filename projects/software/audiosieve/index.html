LOCAL-FIRST
Media Safety Boundary
AudioSieve reads local media through browser object URLs and Web Audio. The supplied page does not upload local files. IndexedDB stores derived metadata, fingerprints, and catalog tag edits; original audio bytes remain outside persistent browser storage unless the user explicitly downloads a processed copy.
