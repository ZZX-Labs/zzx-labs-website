# PRONER
`/projects/software/proner/`

Private adult content organizer and encrypted library system for managing notes, bookmarks, media references, and research collections. Cross-platform builds include Android (.apk) and desktop binaries for Linux, macOS, and Windows.

The browser companion is a local-first catalog for notes, bookmarks, research records, and media references. It computes SHA-256 for selected local media references and supports encrypted library export/import with PBKDF2 + AES-256-GCM.

The static page does not upload or persist media files. This project is for lawful adult content and research only.
