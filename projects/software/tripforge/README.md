# TripForge

`/projects/software/tripforge/`

TripForge is a global travel planning and logistics system for itinerary creation, budgeting, booking integration, and experience optimization across cities and remote destinations.

The browser companion provides itinerary stop creation, timeline rendering, manual booking/reference records, budget tracking by currency without implicit conversion, trip-package JSON export, and calendar ICS export.

Live pricing, booking, inventory, route APIs, and synchronization remain backend/integration capabilities and are not fabricated by the static page.
