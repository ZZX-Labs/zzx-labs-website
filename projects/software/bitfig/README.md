# BitFig

Bitcoin Core / Knots configuration designer.

**Version:** 0.2.0-alpha  
**License:** MIT

The browser edition generates, edits, validates, compares, imports, and exports `bitcoin.conf` files. It also produces a rollback-aware deployment checklist.

It does not accept SSH keys, passwords, or RPC credentials and does not overwrite live nodes. Remote Paramiko deployment remains native-side.

Deploy directly into:

```text
/projects/software/bitfig/
```

`logo.png` is intentionally not included in this archive.
