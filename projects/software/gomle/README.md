# Gomle

Functional browser adaptation of the single-site isolated media browser.

Implements origin locking, sandboxed iframe navigation, local audio/video playback, gain and playback-rate controls, and exportable session logs. Third-party sites may refuse iframe embedding via CSP/X-Frame-Options; the native QtWebEngine application has different capabilities.

Deploy directly into `/projects/software/gomle/`.

`logo.png` is intentionally omitted.
