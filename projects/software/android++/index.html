PROJECT

        
Android++

        

          Android++ is an offline Android code editor inspired by the fast multi-document
          workflow of Notepad++, with local data transformations and encrypted-note workflows.
          The web edition runs the editor directly in the browser and isolates APK handling
          into a separate optional layer.

LOCAL-FIRST

      
Security Boundary

      

        Editor files remain local unless the user explicitly downloads them. The APK parser
        does not install packages or execute DEX. Extracted WebView content is launched only
        in a sandboxed iframe with a restrictive Content Security Policy blocking network
        connections, forms, top navigation, and same-origin privilege.
