# memeantix — SDO

`/projects/software/memeantix/sdo/`

memeantix — SDO (Scenario Deployment Operations) is a scheduling and release-control module that automates meme distribution sequences and controlled campaign timing.

**INTERNAL – Not for public distribution.**

SDO means **Scenario Deployment Operations**.

The web module provides a controlled release-timeline builder, explicit release gates, dry-run timing, manual-handoff semantics, and scenario JSON export.

The static page does not store platform credentials or automatically publish to external services.
