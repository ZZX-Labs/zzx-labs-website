# memeantix — FSO

`/projects/software/memeantix/fso/`

memeantix — FSO is a specialized campaign asset pack providing automation presets, scripting utilities, and distribution-ready meme templates for rapid deployment.

**INTERNAL – Not for public distribution.**

This nested FSO module provides local automation presets for creative review, A/B asset export, archive packaging, SDO schedule handoff, aggregate telemetry review, and custom step pipelines.

The web build does not store social-platform credentials or auto-publish externally.
