# memeantix — CWG

`/projects/software/memeantix-cwg/`

memeantix — CWG (Chimps with Guns) is a themed campaign module containing art packs, meme prompts, and distribution tooling for memeantix’s campaign engine.

**INTERNAL – Not for public distribution.**

CWG means **Chimps with Guns**.

## Browser module

The web page is a themed creative-asset module containing:

- six cartoon/comic/manga-style art-direction presets;
- absurdist campaign tones;
- headline seeds;
- caption and format controls;
- current-variant JSON;
- module-package export compatible with memeantix workflows.

This pack contains visual/prompt concepts only. It does not provide weapon construction, procurement, targeting, or operational instructions.
