PROJECT

        
Overview

        

          4DV augments an existing video with synchronized contextual layers rather than
          rewriting the original media. Text, audio, and secondary-video tracks remain
          independent and are activated according to the source timeline.

NON-DESTRUCTIVE

      
Media Safety Boundary

      

        The supplied browser implementation reads user-selected media through object URLs.
        It does not overwrite the source video, does not upload local media, and stores the
        4DV temporal-layer model separately from the original file.
