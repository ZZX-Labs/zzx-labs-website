# ZZX++

`/projects/software/zzxpp/`

Desktop C++/Python GUI/CLI counterpart to Android++, focused on offline-first editing, encryption tooling, and transformation pipelines with extensible plugin surfaces.

The browser workbench implements multi-document local editing, local file open/save, literal/regex find-replace, common text/data transforms, SHA-256, an AES-256-GCM local encrypted-note vault, and declarative plugin recipes. Native Python CLI and minimal Qt/C++ editor sources are included.
