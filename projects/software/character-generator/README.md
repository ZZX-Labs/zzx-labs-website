# Character Generator

Promptable deterministic character builder for games and fiction.

**Version:** 0.1.0-alpha  
**License:** MIT

The browser edition generates reproducible structured characters from a seed and prompt, supports profile editing and story hooks, renders reusable templates, and exports JSON/Markdown.

Deploy directly into `/projects/software/character-generator/`.

`logo.png` is intentionally omitted until final artwork is supplied.
