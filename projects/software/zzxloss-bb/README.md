# ZZXLOSS-BB

`/projects/software/zzxloss-bb/`

ZZXLOSS-BB is a structured book authoring and publishing system for assembling technical manuals, whitepapers, and narrative works with modular content blocks, versioning, and export pipelines.

The browser builder supports book metadata, modular chapters, reordering, live preview, word counts, Markdown/HTML/LaTeX/JSON export, and a structured JSON book schema. A native `pypandoc` build helper is included for real Pandoc-backed conversions when Pandoc is installed.

Version: `0.1.0-alpha`
