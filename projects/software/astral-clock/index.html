PHYSICAL MODEL

Model

Astral Clock uses a transparent approximation intended for simulation and engineering visualization, not precision ephemeris or relativistic navigation.

Weak-field surface proper-time rate approximation: dτ/dt ≈ 1 - GM/(r c²) - v²/(2 c²) where: G = 6.67430×10⁻¹¹ m³ kg⁻¹ s⁻² c = 299,792,458 m/s M = body mass r = body radius v = combined modeled rotational/external velocity Clock mapping relative to an Earth reference epoch: τ_body(t) = epoch + (t - epoch) × rate_body / rate_Earth Signal delay: t_signal = distance / c The browser model uses representative constants and distances. It does not claim observer-independent simultaneity, exact orbital ephemerides, full general-relativistic metric integration, Shapiro delay, atmospheric delay, or precision spacecraft-navigation accuracy.
