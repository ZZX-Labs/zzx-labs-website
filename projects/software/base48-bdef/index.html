CANONICAL ALPHABET
Reference
Base48 starts from Bitcoin's Base58 alphabet and removes C/c, S/s, P/p, A/a, and M/m.
This implementation preserves leading zero bytes using the first alphabet character 1, matching the familiar Base58-style leading-zero convention.
