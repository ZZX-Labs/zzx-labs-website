Blog API

Read-only machine-readable access to ZZX-Labs research articles, archival metadata, artwork references, tags, and syndicated entries. These static endpoints run on GitHub Pages without a Python or Flask server.

Publication status: The catalog includes recovered archival drafts. A record appearing in the public catalog does not establish that its historical publication date or technical claims have been verified.

Developer integration

Request the JSON index directly from a CLI, application, or HTTP client:

curl -fsSL https://zzx-labs.io/blog/api/posts.json

Example data fields include title, url, description, date, category, tags, thumb, and status. Fields are editorial metadata, not authentication or authoring controls.

Posting, editing, and deleting articles

The public website does not expose a submission endpoint. Draft creation, image uploads, edits, publication, and deletion belong to the separately hosted authenticated ZZX-BLOG publisher service. Its private API must not be exposed as a public static HTML link or treated as a GET endpoint.

For editorial access, contact the ZZX-Labs editorial team. For article browsing, return to the Journal, Archive, or RSS page.
